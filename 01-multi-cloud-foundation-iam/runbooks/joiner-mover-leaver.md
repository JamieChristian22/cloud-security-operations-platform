# Joiner–Mover–Leaver Runbook
## Joiner
Verify HR-approved identity → create standard account → assign department group → enforce MFA registration → grant app access by group → validate sign-in → close ticket with approvals.
## Mover
Confirm manager approval → add new role group → remove incompatible old access → check separation of duties → validate required apps → document changes.
## Leaver
Disable sign-in immediately at effective time → revoke sessions → remove groups/roles → rotate owned service credentials → transfer business data → confirm no active cloud keys → retain audit evidence.
