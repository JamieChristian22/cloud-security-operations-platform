# Security policy

This repository is an educational security lab. All committed incident records and sample identifiers are synthetic. Do not run attack simulations against systems without authorization.

Do not open a public issue containing credentials or sensitive incident data. Revoke exposed credentials first, preserve incident evidence privately, and use the repository owner's available private contact channel for sensitive reporting. The project has no claimed 24-hour response commitment or dedicated security team.

Use short-lived credentials for optional collectors and deployment. The collector only reads EC2 metadata in an explicit region. The offline suite requires no cloud credentials. Review third-party dependencies and recorded scanner exceptions before operational use.
