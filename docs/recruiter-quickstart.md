# Recruiter / Hiring Manager Quick Start

This repository does not require screenshots or a video demo to understand the work. Start with the root `README.md`, then use [the evidence map](../PORTFOLIO-EVIDENCE.md) and [project index](../PROJECT-INDEX.md) as proof maps.

For cloud/IAM roles, review Project 01. For support/operations roles, review Project 02. For SOC/security roles, review Project 03. For Python/automation depth, review Project 04. For Terraform/DevOps roles, review Project 05 and [the CI workflow](../.github/workflows/ci.yml).

All company names, users, incidents, metrics, and logs are simulated. Technical artifacts are intentionally included in source form so the work can be inspected directly.
