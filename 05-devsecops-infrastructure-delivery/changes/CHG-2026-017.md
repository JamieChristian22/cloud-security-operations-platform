# CHG-2026-017 — Protect Demo Asset Storage
**Requester:** Application Team (simulated)  
**Risk:** High  
**Original request:** Make an object-storage bucket public so a demo page can load assets directly.

## Security Review
Rejected. Public bucket access creates unnecessary exposure and conflicts with the platform baseline.

## Approved Design
Keep the bucket private and deliver approved content through a controlled application/CDN path with explicit access. Public access block remains enabled.

## Validation
IaC formatting/validation passes; policy test confirms `public=false`; no internet-exposed management ports; no wildcard admin policy.

## Rollback
Revert the pull request/commit and re-apply the last approved Terraform configuration.

## Outcome
Risky implementation was prevented before deployment, while the business requirement remained achievable through a safer design.
